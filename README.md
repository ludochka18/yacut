# YaCut

Учебный сервис сокращения ссылок на Flask с REST API и асинхронной
загрузкой нескольких файлов на Яндекс Диск через aiohttp.
Каркас и исходные тесты: https://github.com/yandex-praktikum/yacut.

## Запуск

Проверено на Python 3.12. Рекомендуется Python 3.11–3.12.

```bash
python3 -m venv venv
source venv/bin/activate
# Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` задайте собственный `SECRET_KEY` (например, сгенерируйте его командой
`python -c "import secrets; print(secrets.token_hex(32))"`).
`DATABASE_URI` по умолчанию — `sqlite:///db.sqlite3`, файл SQLite создаётся
в каталоге `instance`. Для загрузки файлов добавьте `DISK_TOKEN`, полученный
для собственного OAuth-приложения Яндекс Диска с доступом
`cloud_api:disk.app_folder` и `cloud_api:disk.info`.
Не публикуйте `.env` или токен.

```bash
flask --app yacut db upgrade
flask --app yacut run
```

Откройте http://127.0.0.1:5000/. Загрузка файлов: `/files`.
Без `DISK_TOKEN` сокращение ссылок и API работают; форма файлов покажет
сообщение о необходимости настройки токена.

## Возможности

- Автоматические идентификаторы из шести латинских букв и цифр.
- Пользовательские идентификаторы длиной до 16 символов.
- Проверка занятых имён, резервирование `files`, `api`, `static`.
- Уникальность на уровне базы и повторная генерация при коллизиях.
- GET по короткой ссылке перенаправляет на исходный адрес с кодом 302.
- Несколько файлов загружаются параллельно через `asyncio.gather` и aiohttp.
- Имена файлов на Диске получают уникальный префикс: существующие файлы
  не перезаписываются. Успешные результаты сохраняются даже при ошибке
  загрузки другого файла; для ошибок выводится сообщение.
- Суммарный размер запроса с файлами ограничен 32 МБ.
- Шаблоны Jinja, локальная статика Bootstrap, CSRF-защита веб-форм.
- Собственные HTML-страницы ошибок и JSON-ошибки API.

Ссылки скачивания, возвращённые Яндекс Диском, могут иметь ограниченный
срок действия. Эта учебная реализация сохраняет полученный адрес как
исходную ссылку согласно алгоритму из задания.

## API

`POST /api/id/` — JSON `{"url": "https://example.com", "custom_id": "example"}`.
Поле `custom_id` необязательно. Успешный ответ: 201 с `url` и `short_link`.

`GET /api/id/<short_id>/` — 200 с `url`, либо 404 с `message`.
Ошибки валидации возвращают 400 с `message`.
Спецификация: `openapi.yml`. Коллекция Postman: `postman_collection/`.

## Проверки

```bash
pytest
flake8 yacut settings.py
```

В проекте 30 неизменённых тестов исходного каркаса и 21 дополнительная
проверка. Тесты Диска подменяют HTTP-ответы: реальный токен не требуется.
Проверяются конкуррентность запросов, отсутствие OAuth-заголовка при PUT,
декодирование Location, уникальные пути, частичные ошибки и веб-форма.
Реальная загрузка в Яндекс Диск требует отдельной проверки с вашим токеном.
Скрытые тесты Практикума недоступны локально.

## Структура

- `yacut/models.py` — модель URLMap, валидация, генерация идентификаторов.
- `yacut/views.py` — главная страница, файлы и перенаправления.
- `yacut/api_views.py` — REST API.
- `yacut/disk.py` — асинхронные запросы к Яндекс Диску.
- `yacut/forms.py` — формы Flask-WTF.
- `yacut/error_handlers.py` — обработчики ошибок.
- `yacut/templates/`, `yacut/static/` — шаблоны и статика.
- `migrations/` — миграции базы данных.

Для сдачи используйте архив исходников без `.env`, базы данных и venv.
